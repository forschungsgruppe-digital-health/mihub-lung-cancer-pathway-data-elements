# Phase `screening` — Krebsfrüherkennung (LDCT-Lungenkrebs-Screening)

Dieser Ordner nimmt die Datenelemente der Screening-Episode auf. Rechtsgrundlagen: Lungenkrebs-Früherkennungs-Verordnung
(LuKrFrühErkV vom 15.05.2024, in Kraft 01.07.2024) und G-BA Krebsfrüherkennungs-Richtlinie, Abschnitt D.III (in Kraft
12.03.2026; GKV-Leistung, Abrechnung nach EBM seit 01.04.2026). Die Elemente entstehen aus der Datenelement-Erhebung
2026-10/11 — Quellen-Dossier, Prozessschritt-Matrix und vorbefüllte Erhebungsmappe unter
[`../../docs/screening/`](../../docs/screening/). Bis zur Übernahme der ersten Elemente bleibt der Ordner leer
(`build-catalog.py` zeigt die Phase ohne Zeilen).
